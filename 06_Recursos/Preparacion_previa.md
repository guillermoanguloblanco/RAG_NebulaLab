# Preparación antes de clase (flipped classroom)
Tiempo estimado: 40–60 minutos.

1. Repasar la arquitectura RAG (documentos → fragmentos → embeddings → base vectorial → recuperación → generación).
2. Leer `02_Proyecto_RAG/README.md` y preparar Python y VS Code.
3. Instalar las dependencias y ejecutar `python -m src.rag index`.
4. Responder: ¿qué diferencia hay entre similitud semántica y coincidencia de palabras? ¿Por qué citar fuentes no garantiza que una respuesta sea correcta?
5. Leer los documentos de ejemplo, detectar el borrador obsoleto y explicar qué fuente debería prevalecer.

- https://docs.trychroma.com/
- https://ai.google.dev/gemini-api/docs
- https://ai.google.dev/gemini-api/docs/embeddings
